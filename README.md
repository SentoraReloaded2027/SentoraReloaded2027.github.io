# Sentora 2027 website

The site at https://sentorareloaded2027.github.io: one page (`index.html`, no build step) served by
GitHub Pages from the `main` branch. The panel itself lives in
[RusTus/sentora-core-2027](https://github.com/RusTus/sentora-core-2027) and its installers in
[RusTus/sentora-installers-2027](https://github.com/RusTus/sentora-installers-2027).
